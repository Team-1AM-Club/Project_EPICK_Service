# W2 C-01 호환 구현 설계

사용자 승인: 2026-09-16 입력 어댑터, 이중 순번, 복구, 테스트/회신 자료 구현 승인.
팀 계약 채택/운영 배포 승인은 별개다. 기존 0.1-draft는 유지한다.

## 경계
- 신규 `w3_knowledge.c01` 및 `/c01/v1/*`, 버전 `w3-c01/0.2-candidate`.
- 받은 W2 payload JSON Schema 원본을 패키지에 포함하고 Draft202012 + format 검증한다.
- envelope 1.0, producer w2, aggregate source, event type별 payload 일치를 검증한다.
- UUID, accuracy, replacement_ref, static_html을 보존한다. 날짜 unknown을 추정하지 않는다.
- 기존 draft DB와 C01 DB를 consumer identity로 분리한다.

## 순번/차단
- Source당 연속 event_cursor / required_event_cursor와 Source당 restriction_revision /
  required_restriction_revision을 분리한다. restriction 순번 범위는 W3 제안이다.
- 실행 시 restriction_scope=source 또는 version 필수. version 모드에서 null은 Source 전체.
  이 의미는 팀 공동 확인 항목이며 기본값으로 몰래 선택하지 않는다.
- 이벤트 순번 누락, ID/순번 충돌, restriction 순번 누락은 검색/인덱스 ACK 차단.
- 모든 종류의 이벤트를 순서대로 적용한다. 새 버전은 제한 해제 이벤트가 아니다.
- restriction_id별 최신 상태를 유지한다. 하나의 cleared가 다른 active를 해제하지 않는다.
- 마지막 version 이벤트의 정확한 extraction/representation/normalization 키를 사용한다.
  이전 버전을 가리키는 제한은 그 버전으로 유지한다.
- Observation unavailable은 보수적으로 차단한다. release만으로 이를 되돌리지 않는다.

## 복구/보관
- replay는 event cursor 기반, after_cursor/high_watermark/retention_floor_cursor를 명시한다.
  W2 envelope에 outbox 시간이 없으므로 게시 날짜를 대신 쓰지 않는다.
- snapshot은 한 Source의 원자적 전체 상태: cursor, 최신 version들, restriction_id별
  최신 restriction event, 최신 observation. 모든 event revision <= cursor.
- replay batch 및 snapshot은 BEGIN IMMEDIATE 단일 트랜잭션. snapshot은 알려진 high-watermark
  미만이면 거절, 항상 index 폐기, history_complete=false. conflict는 replay로 자동 해제하지 않는다.
- 수신 이력은 원문 SHA256과 본문 없는 projection만 저장한다. index 본문은 operator가
  전달하되 허용된 Evidence 텍스트 해시와 비교하고 TTL 내에서만 보관한다.
- 정책 unknown/denied를 허용으로 해석하지 않는다. normalized body 저장은 이번 후보에서
  지원하지 않고 excerpts_only만 지원한다. 물리적 파일/WAL/백업 삭제는 별도 운영 정책이다.

## W4
- 별도 C01 signal/status 모델: 두 순번 모두 명시, ambiguous required_revision 없음.
- receipt COMMITTED, index_ack READY, delivery ACK를 분리한다.
- generation 기반 cache invalidation + 조회 시 최신 status 검사.
- legacy guard와 C01 상태 혼용 금지. 새 guard는 같은 키와 generation을 전후 검사한다.

## 검증
받은 정상 4/오류 2 fixture, 교차 이벤트 타입, UUID, gap/duplicate/conflict, restart,
replay 경계, stale snapshot, 제한 해제/복수 제한, policy/TTL/mismatch, HTTP role, W4 cache,
기존 회귀 테스트를 실행한다. 실제 W2/W4 서버 연동과 GitHub CI는 미실행으로 구분한다.
