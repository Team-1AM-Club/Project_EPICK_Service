# W3 구조화 계약 결정 기록

**기능**: 수집 자료의 근거 검증과 지식 구조화
**기준 계약**: W3 내부 `0.2.0-draft` / PM 관측 입력 `0.1.0-draft, PROPOSED`
**상태**: 실제 합의·운영 증거가 필요한 항목은 OPEN으로 유지한다. 이 문서는 그 결정을 대신하지 않는다.

## 역할과 소비 경계

| 영역 | 소유하는 기준 기록·결정 | W3가 받거나 반환하는 것 |
|---|---|---|
| W1 | 인증 주체, 현재 권한, 보존 참조, 사용자 선택·Job·삭제 제어 | 신뢰 문맥·정책 판정, 제한·처리 상태 |
| W2 | Source/SourceVersion, 원문·첨부 수집/파싱, 보존 표현, 수집 시 관측 | 원래 ID·버전·Evidence·첨부 관계·수집 보고 |
| W3 | 후보 구조화, 근거 대조, 검사 출처·제한, KnowledgeBundle 파생 결과 | 검증·활용 상태와 근거/제한을 W4에 제공 |
| W4 | 문항 해석, 원 경험 검증, 최종 부합·추천·설명 | W3 결과를 입력으로 사용하며 지원요건/최종 적합성을 W3에 위임하지 않음 |

## 버전과 입력 형식

| 항목 | 상태 | 적용 방식 |
|---|---|---|
| W3 내부 구조 계약 0.2.0-draft | OPEN | strict 내부 모델과 어댑터의 출력 기준. 소비자 공동 검토 전 운영 계약 아님. |
| 기존 요약 입력 | OPEN | 원문 없는 제한 진단 어댑터. 요약을 Evidence로 승격하지 않음. |
| PM observed 입력 0.1.0-draft / PROPOSED | OPEN | SourceVersion/Evidence·첨부 참조를 보존하는 로컬 진단 어댑터. 샘플 enum/ID를 제품 표준으로 고정하지 않음. |
| 공유 W2→W3→W4 버전·호환·되돌림 | OPEN — G-01/G-03/G-05 | W2/W3/W1/W4가 소유자·소비자·지원 기간·적용/되돌림 순서를 기록해야 함. 미지원 버전은 조용히 변환하지 않고 거부. |

## 근거·위치·해시의 OPEN 항목

| 항목 | 현재 설계 | 실제 적용 전 필요한 증거 |
|---|---|---|
| SourceVersion 식별 | W2가 제공한 불투명 ID를 보존 | 운영 ID 발급·수정/재게시·파서 변경 정책과 충돌 처리 합의 |
| 발췌 위치 | 보존 발췌의 코드포인트 위치와 원래 노드/페이지/문단 위치를 구분 | locator 기준 텍스트·정규화·안정성·소비자 해석의 공동 검토 |
| 해시 | 대상·알고리즘·인코딩·변환 규칙을 함께 보존 | W2가 제공한 원문/첨부/추출 전문 digest의 신뢰 계약, 최소 발췌 기대 digest/증빙 제공 |
| 수집 시 확인 | UPSTREAM_REPORTED로 원래 보고를 보존 | 검사 주체·시점·방법·결과의 신뢰/수용 기준. W3 현재 PASS와 혼동 금지 |
| 원문·첨부 보존 | 최소 허용 발췌/참조만 사용 | Source별 수집·외부 처리·보관·재배포 허용(G-04/G-05)과 W1 보존 참조 계약 |
| 공용 결과 활용 | PolicyPort가 현재 허용을 판정 | W1 인증·철회/삭제·외부 전송·반환 전 재검사 실제 연동(G-03/G-04) |

## 구현과 운영의 분리

합성 fixture·대역은 로컬 계약과 상태 계산을 검증한다.
PM 파일의 로컬 진단은 제공된 JSON 참조·ID·상태만 확인한다.
이들은 수집 사이트의 현재 원문, 전체 해시, 첨부 내용, 모델 품질, 공용 활용 허용을 검증하는 결과가 아니다.

G-02 실제 Solar PoC는 등록된 합성 입력과 명시적 live 실행 설정이 있을 때만 수행한다.
G-03~G-05의 실제 권한·보존·삭제·외부 처리 증거가 없으면 운영 활용을 차단하고 OPEN으로 남긴다.
W3는 OCR, 재수집, 사용자 선택, 인증, Job, Graph/Vector 적재, 최종 추천을 구현하지 않는다.

## 구현 검증 시점 기록 — 2026-09-07

| 확인 대상 | 관찰 결과 | 상태와 후속 조건 |
|---|---|---|
| PM observed 로컬 진단 | 8개 SourceVersion을 입력으로 읽었고, `LIMITED` 결과와 12개 제한을 반환했다. 원문·응답 전문은 출력하거나 공개 fixture에 저장하지 않았다. | 제공 발췌의 원본 재현성·기대 digest가 없으므로 Claim 검증 완료로 전환하지 않는다. `tmp/w3-local-review/pm-analysis.json`은 로컬 검토 초안이며 배포 제외다. |
| 기존 요약 샘플 진단 | 2개 SourceVersion을 제한 진단으로 처리했다. 요약은 Evidence로 승격하지 않았다. | 원문 SourceVersion·위치·digest가 제공되기 전에는 검증 Claim을 만들지 않는다. |
| W2/W4 계약 합의 | 실제 소유자·소비자 공동 검토 증거가 제공되지 않았다. | G-01은 OPEN이다. 0.2.0-draft 결과의 공유·운영 적용을 차단한다. |
| W1 권한·보존·철회/삭제 연동 | 실제 처리·공유 허용 증거가 제공되지 않았다. 합성 PolicyPort 경계 테스트만 통과했다. | G-03/G-04/G-05는 OPEN이다. 합성 결과를 실제 연동 증거로 대체하지 않는다. |
| Solar provider PoC | provider 호출 허용·설정이 제공되지 않아 실행하지 않았다. | G-02는 OPEN이다. `--run-live`와 승인된 설정·목적이 갖춰진 별도 실행에서만 기록한다. |
