# EPICK 디자인 시스템

현재 구현 기준 · 2026-09-20

기존 디자인 시스템 MD는 프로젝트에서 발견되지 않았다. 이 문서는 README의 Figma 참조와 `app/figma-theme.css`에 적용된 기준을 정리한 것이다. 별도의 원본 디자인 명세가 제공되면 대조하여 갱신한다.

## 상호작용

- 입력과 드롭다운 트리거: 기본 1px 테두리. 포커스 시 같은 테두리만 민트로 변경한다. 별도 outline과 ring을 겹치지 않는다.
- 검색창: 내부 입력 요소가 아니라 둥근 외부 컨테이너에 `:focus-within` 테두리를 적용한다.
- 드롭다운 팝업: 차콜 배경, 1px 반투명 테두리, 20px 곡률. 내부 항목은 10px 곡률.
- 드롭다운 선택·키보드 이동: 어두운 민트 배경과 민트 글자·체크 표시. Escape로 닫고 트리거로 포커스를 돌린다.
- 일반 버튼과 링크: 키보드 접근 시 민트 포커스 윤곽선을 유지한다.
- 분석 시작·다시 분석: 공통 `--primary` 색상을 사용한다. 화면별 파란색 하드코딩을 추가하지 않는다.

## 글꼴과 반응형

- 기본 글꼴: Pretendard. 영문 기술 이름: Outfit.
- 화면 제목은 주로 20–21px, 본문·입력은 14–16px. 모바일 입력은 16px.
- 모바일 하단 내비게이션과 단일 열 입력 폼을 유지한다.
- 팝업은 뷰포트 높이 안에서 스크롤되며 페이지 가로 넘침이 없어야 한다.

## 구현 및 점검

- 토큰과 제품 공통 시각 규칙: `app/figma-theme.css`.
- 드롭다운 공통 컴포넌트: `components/ui/select.tsx`. Portal로 렌더링되는 목록에도 `[data-slot=select-content]` 규칙을 적용한다.
- 기존 `app/globals.css`에는 초기 화면의 레거시 스타일이 남아 있다. 새 화면에서는 이 문서의 토큰을 사용하고, 더 구체적인 기존 선택자가 색상을 덮어쓰는지 확인한다.
- 기본·호버·포커스·열림·선택·비활성 상태를 확인한다. 경험 입력과 지원 작업의 드롭다운을 모두 확인한다.
